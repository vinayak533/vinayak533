## About Me

I build AI systems that make decisions, not just predictions.

Every model I've shipped started the same way: a messy dataset and a question nobody had time to answer. So I learned to answer it end to end — the pipeline feeding the model, the API standing in front of it, and the container it ships inside. Today that work is agentic: systems that reason, retrieve, route across models, and choose their own tools.
